# Sulai — Portfolio

Personal portfolio site, built 1:1 from the Figma design "Sulai-portfolio" (1440px desktop frame),
with derived tablet and mobile layouts.

- Plain HTML + CSS, no build step: `index.html`, `styles.css`, `assets/`
- Fonts: Anton, Manrope, Host Grotesk (Google Fonts)
- Hosted on Vercel; every push to `main` redeploys.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
